# MVP 10: Shop people want — implementation plan

> For agentic workers: superpowers:test-driven-development on every step. Backend gate
> `./gradlew spotlessApply build` (one Gradle build at a time; run detached and poll when long); client
> gate `npm run lint && npm test && npm run build`. Commit per task; `Closes #n` on the last commit.

**Goal:** a catalogue worth wanting: two satire decks (one bought, one earned by a win streak), new
backs/tables/frames, phrase emotes, weekly drops with a countdown, and lock badges.

**Spec:** `docs/superpowers/specs/2026-10-13-popular-polish-design.md` §3 and §5 (Shop).

**Constraints:** schema only via a NEW changeset `013-shop-unlocks.sql` (shop columns only); never edit
010. Module rules (ArchUnit): monetization owns the shop. The player's best win streak belongs to the
account module and is added by MVP 11 (changeset 014), which runs in parallel. So `ShopService` depends
on a port `cardwar.monetization.grant.StreakSource { int bestWinStreak(UUID playerId); }` with a
default bean in monetization config returning 0 (`@ConditionalOnMissingBean`); MVP 11 provides the
account-backed bean. Say so in the issue comment.

Kyiv time for drop weeks: `ZoneId.of("Europe/Kyiv")`; ISO week from `java.time.temporal.IsoFields`.

## Interfaces

- `shop_item` new columns: `unlock_kind VARCHAR(16) NOT NULL DEFAULT 'COINS'` (check `IN ('COINS',
  'WIN_STREAK')`), `unlock_value INT NOT NULL DEFAULT 0`, `drop_slot INT NULL` (check 0..3).
- `ShopItemView(code, type, contentRef, name, price, owned, equipped, unlock: UnlockView | null,
  availableUntil: Instant | null)` with `UnlockView(kind, value, met)`; `unlock` is null for plain
  COINS items without a drop; a drop item carries `availableUntil` only while on sale; off-week drop
  items are returned with `unlock = { kind: "DROP", value: slot, met: false }` and `availableUntil = null`.
- `ShopView` gains `drops: ShopItemView[]` (this week's drop items, also present in `items`).
- `POST /shop/items/{code}/buy`: WIN_STREAK items → 400 `NOT_FOR_SALE`; off-week drop → 400 `NOT_ON_SALE`;
  WIN_STREAK items are granted on `GET /shop` when met (`owned_item.source = 'STREAK'`).
- Client `ShopItemView` type mirrors the above; `src/ui/cosmetics.tsx` gains refs for every new
  back/table/frame and `EMOTE_PHRASES: Record<string, { glyph: string; text: string }>`.

- Buying a drop item in the last second of its week: server decides, client only displays.
- CSP: all new visuals are CSS; no external images.
