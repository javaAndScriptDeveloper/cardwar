# MVP 1: Observability — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** Technical and business metrics plus debuggable logs in Grafana, in the submissions-checker pattern.

**Architecture:** Micrometer Prometheus registry on the app (`/actuator/prometheus`, reachable on the compose network
only; nginx answers 404 for `/actuator/prometheus` and `/actuator/metrics`). Business counters live in one
`cardwar.metrics.GameMetrics` component that services call. Logs become JSON (Spring Boot structured logging,
logstash format) with an MDC `requestId` from a filter that also echoes `X-Request-Id`. Grafana Alloy scrapes the app
and tails container logs, remote-writing to Grafana Cloud in production and to a throwaway Prometheus + Loki locally
(`make observability-up`). Dashboards and alert rules are generated by `observability/grafana/build.mjs` into
committed JSON; a Node test keeps dashboard metric names ⊆ the metrics the app exports.

**Tech Stack:** Spring Boot 4 Actuator + Micrometer, Grafana Alloy 1.10, Prometheus 3, Loki 3.5, Grafana 11, Node 24.

**Spec:** `docs/superpowers/specs/2026-10-12-mvp-design.md` §8.

## Global Constraints

- No player id, duel id, invite id or username as a metric label; label values come from closed enums only.
- Logs carry ids only; never tokens, initData, cards, hands, invoice payloads (CLAUDE.md).
- `/actuator/prometheus` never reachable through nginx.
- Grafana Cloud credentials only in `/opt/cardwar/.env` (`GRAFANA_CLOUD_*`, `GRAFANA_URL`, `GRAFANA_API_TOKEN`);
  Alloy runs in production only with `COMPOSE_PROFILES=observability`.
- Every query in a dashboard filters on `job="cardwar"`; logs on `app="cardwar"`.
- Gates: `./gradlew spotlessApply build`, client gates unchanged, `scripts/smoke.sh`, `make e2e`.

## Review Focus

1. Anonymous request to `/actuator/prometheus` through nginx → 404 (smoke step).
2. A client-supplied `X-Request-Id` that is huge or contains newlines/JSON → replaced by a generated id (log injection).
3. Metrics labels from engine enums only — an unexpected move type must not create a new series (enum-typed API).
4. Metrics endpoint unauthenticated inside the network but the rest of `/actuator` (except health/info) still protected.
5. Business counters do not double-count a move that loses the CAS race (409).

## Tasks

1. **Prometheus endpoint** — add `io.micrometer:micrometer-registry-prometheus`; permit `/actuator/prometheus` in
   `SecurityConfig`; nginx `location ~ ^/actuator/(prometheus|metrics)` → 404; common tag `application=cardwar`;
   integration test: GET `/actuator/prometheus` 200 with `http_server_requests_seconds` and `jvm_memory`; smoke step
   asserting 404 through nginx.
2. **Request id + JSON logs** — `cardwar.config.RequestIdFilter` (first in chain): accept `X-Request-Id` matching
   `[A-Za-z0-9-]{8,64}`, else generate UUID; MDC `requestId`; echo header. Prod profile:
   `logging.structured.format.console: logstash`. nginx forwards `$request_id` as `X-Request-Id` and logs JSON.
   Tests: echo valid id, replace invalid id, generate when absent.
3. **Game metrics** — `cardwar.metrics.GameMetrics` with counters `cardwar_signins_total{method}`,
   `cardwar_duels_started_total{mode}`, `cardwar_duels_finished_total{result,reason}`,
   `cardwar_moves_total{type,outcome}`, `cardwar_invites_total{event}`, `cardwar_bot_updates_total{outcome}`,
   gauge `cardwar_sse_streams_open`. Wire from services. Integration test reads the registry after a duel.
4. **Alloy + harness** — `observability/alloy/config.alloy`, `observability/local/*`, compose services
   `prometheus`, `loki`, `grafana`, `alloy` behind profile `observability` (local harness services under an extra
   profile `observability-local`), Makefile targets `observability-up/down`, `alloy-logs`.
5. **Dashboards + alerts** — `observability/grafana/build.mjs` → `cardwar-technical.json`, `cardwar-business.json`,
   `cardwar-logs.json`, `alerting/alert-rules.yaml`; `push.mjs`; `node --test observability/grafana/build.test.mjs`
   in CI; `make dashboards`, `make alerting`.
6. **Docs + deploy** — `docs/observability.md`, README/CLAUDE.md pointers, `.env.example`; deploy; verify
   `/actuator/prometheus` 404 publicly and 200 inside the network.
